# Odin Recipes

A responsive, accessible recipe collection built with plain HTML and CSS. Browse the home page to choose a recipe, then follow its ingredient list and directions.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Project structure

- `index.html` — recipe collection and home page
- `recipes/` — individual recipe pages
- `CSS/style.css` — shared responsive styles
- `img/` — recipe and hero images
